# makiety-zdjecia

Zdjęcia tylko do makiet w Google Stitch (linki przez jsDelivr). Nie do stron docelowych - tam zdjęcia konwertuje Antigravity do WebP.

- Struktura: `[klient]/hero.jpg` (2880 x 1520, proporcje sekcji hero 1440 x 760), `[klient]/usluga-1.jpg` itd.
- Link: `https://cdn.jsdelivr.net/gh/szymulinda/makiety-zdjecia@main/[klient]/[plik]`
- Poprawiona wersja zawsze pod nową nazwą (`hero-v2.jpg`), bo jsDelivr długo trzyma stare pliki.
- Bez prywatnych zdjęć, dokumentów i twarzy klientów - repo jest publiczne.
